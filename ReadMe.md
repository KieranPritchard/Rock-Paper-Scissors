## Project Description

### Objective
To create a simple rock, paper, scissors game to practise fundamental python and programming concepts.  The concepts I wanted to practice with this project include: loops, conditional statements, using external libraries
### Technology and Tools Used
* **Language:** Python.
* **Framework/Library:** "random".
* **Tools:** git, VS Code.
### Challenges Faced
I faced one major challenge with this project, that was with setting up the while loop and the conditional statements the project uses. I overcame this by building the bulk of the program inside a while loop, that was set to true. after doing this the code worked as intended.
### Outcome
I successfully created a python program that demonstrates foundational programming knowledge that I learned about, As well as a rock, paper, scissors game in the process.
## How to Use the Project
1. **Clone The Repository:**
	* This saves the code to your local device.
2. **Run The Game:**
	* Open a terminal and navigate to the directory where you have stored the code. To run the code input this in the terminal: `python Rock_Paper_Scissors.py`
3. **Play The Game:**
	* When your prompted, enter your choice: `Rock`, `Paper`, or `Scissors`.
	* To stop playing, input `Quit`.
4. **Game Rules:**
	* The computer player will randomly choose between Rock, Paper, Scissors.
	* The game then compares choices to determine a winner:
		* Rock breaks Scissors
		* Scissors cuts Paper
		* Paper wraps Rock
	* The game will keep track of scores for both the user and the computer.
5. **End The Game:**
	* When `Quit` is entered, the game displays the final scores for that session and stops the program.
